CEIR Read-Only Checker

License activation မပါဘဲ၊ manual altchaData ဖြင့် ဖတ်ရှုနိုင်သော Tampermonkey helper

Activation-free version

ဒီ repo ထဲတွင် license key, fingerprint, third-party auth worker, token cache, auto-retry သို့မဟုတ် captcha bypass မပါဝင်ပါ။ Script သည် read-only endpoint ၄ခုကို မူရင်း CEIR origin တွင်သာ ခေါ်သည်။

Install

  1. Tampermonkey ကို install ပါ။
  2. ceir-checker.user.js ကိုဖွင့်ပြီး install ပါ။
  3. https://ceir.gov.mm/ တွင် verification ပြီးအောင်လုပ်ပါ။
  4. DevTools → Network မှ official CEIR request ၏ altchaData ကိုကူးပြီး panel ထဲထည့်ပါ။

Token ကို script က မသိမ်းပါ၊ refresh မလုပ်ပါ၊ ပြန်ပို့ပြီး redirect မလုပ်ပါ။
