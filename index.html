CEIR Checker — GitHub HTML Mirror

Original: Windows CeirChecker.exe (Go + WebView2) → injects Tampermonkey script into https://ceir.gov.mm/*.

Important: This Pages site is only docs + installer. The tool itself must run on ceir.gov.mm via Tampermonkey. Direct API calls from github.io will fail CORS / Turnstile domain check.

1. Install (recommended)

  1. Install Tampermonkey extension.
  2. Open ceir-checker.user.js in this repo → Tampermonkey → Create new script → paste → Save.
  3. Go to https://ceir.gov.mm/ → solve Turnstile checkbox → panel appears.

2. Why not pure static HTML?

  • Turnstile sitekeys are bound to ceir.gov.mm.
  • Browser controls Origin header — cannot spoof to ceir.gov.mm from github.io.
  • Cloudflare 403 needs background-page verification on the real domain.
  • License server (workers.dev/api/auth/login|verify) still requires key + fingerprint.

To make full Pages app you need your own Turnstile keys + a backend proxy (e.g. Cloudflare Worker forwarding to ceir.gov.mm/openapi/...). That is out of scope for this mirror.
